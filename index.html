Wie die Programmierung grundsätzlich funktioniert
Nach dem Aufrufen des Programmiermodus spielt der Regler 11 Elemente in einer Endlosschleife ab, jedes mit einer eigenen Ton-Signatur (kurze „beep“ = ■, lange „beep—“ = ■■■).
Hörst du das Signal für das gewünschte Element, Gashebel innerhalb von 2 Sekunden nach unten bewegen → du rufst dieses Element auf.
Im Element selbst wird erneut eine Ton-Sequenz durchlaufen, diesmal für die möglichen Werte. Beim gewünschten Wert wieder innerhalb von 2 Sekunden nach unten → Wert wird gespeichert, ein Bestätigungston folgt.
Gashebel oben halten → zurück zur Elemente-Schleife, andere Funktion wählbar. Danach innerhalb von 2 Sekunden nach unten → Programmiermodus wird direkt verlassen.
